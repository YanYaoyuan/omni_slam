## 重新生成

需 FFmpeg / FFprobe 与保存在本机的原始报告、视频及汇报图片；全新克隆可直接浏览本目录预览，但不包含完整源视频。

```bash
python3 scripts/make_readme_media.py --overwrite
```

脚本使用 CPU 完成时间压缩、调色板量化与缩放，不执行模型或 benchmark。`manifest.json` 保存源文件相对路径、SHA256、参数、输出尺寸、帧数与文件大小，便于追溯。原视频静音导出为无限循环 GIF，保留完整时间范围；没有插帧或增加检测内容。
