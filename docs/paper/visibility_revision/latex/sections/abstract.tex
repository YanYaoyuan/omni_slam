\begin{abstract}
Object maps built by lifting and associating image masks can retain neighboring surfaces even when object identities are useful. We present a visibility-guided revision module that tests the geometric support of these fixed assignments using existing observations. The module accumulates support and refutation for each source point, accepts evidence only when projected depth agrees with the measured surface, and abstains at uncertain mask boundaries and unknown pixels. Geometry is revised while object identities, observation ownership, semantic descriptors, and camera poses remain fixed. This isolates geometric refinement from changes in perception or association. With a configuration fixed before evaluation on four new SceneNN sequences, the method improves the strong baseline in all four sequences: mean observed-domain instance PQ increases from 32.376 to 33.218, while all 66 matched ground-truth instances are preserved. Across 221 instances, best-object IoU improves for 100 and decreases for 27. Depth-gate ablation and a fixed-assignment diagnostic explain the effect of the evidence model and evaluation projection. Statistical outlier removal achieves a slightly higher primary mean of 33.268; object-level analysis identifies the threshold-sensitive case responsible for this difference. The results support visibility-conditioned geometric refinement and delineate its limitations under persistent mask contamination.
\end{abstract}
