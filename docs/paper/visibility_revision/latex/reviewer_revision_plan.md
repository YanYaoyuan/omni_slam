## 3. 当前证据缺口与新假设

假设：早期误关联会把几何和支持它的掩码一起放进错误对象，产生相互支持。单纯降低点置信度可能删除表面，却无法恢复正确的对象结构。

研究目标：**保留观测来源，以后续未参与提案的视角验证局部拆分，撤销错误融合并重新分配已有几何，同时控制误拆分。**

这不是已经证实的新贡献。概率更新、保留历史、拆分或图优化分别不是新概念；需要与点级修订、普通图聚类和已有拆分机制直接比较。

首版仅处理静态场景中的误合并，不同时引入动态物体跟踪、全局位姿优化、语义重分类和新的训练网络。初始实验固定现有 SigLIP 描述子；DINO 局部对应仅在证据表明对应不足时考虑，不能与主模块同时变化。

### 模块接口

输入：冻结地图、原始观测的 frame/mask ID、局部点或体素支持、相机位姿、掩码和有效深度。保存 `point -> observations -> current object` 的来源关系，保留合并前局部片段。

步骤：

1. 从共视的不同实例掩码、稳定空间分离和观测关联冲突生成局部二分提案。不能把同帧不同 mask 自动视为不同对象：过分割和重复 mask 需由跨视角证据验证。
2. 在同一输入与有效可见区域内比较“保持”与“拆分”的观测解释误差。加入固定的复杂度惩罚及最低支持要求，防止无限拆分。
3. 提案与验证采用分离的时间块和视角组；相邻近重复帧不能充当独立证据。验证时重新计算 mask-to-part 匹配，不继承争议归属。掩码也不能由该提案重新提示生成后再用作验证证据。
4. 只有保留视角支持改善、覆盖足够且未违反保留约束时提交。缺深度、遮挡或无法区分时保持原状态。首次实验禁止对验证块反复搜索多个提案后挑最好者。
5. 提交只重新分配原有几何，记录旧 ID 到新 ID 的 lineage、操作原因及可撤销日志；不复制同一源点到两个输出实例，不宣称生成了未观测表面。

在线语义：提案产生后等待实际到达的新视角再提交。全序列重放可以验证离线能力，但不能冒充实时在线结果。位姿修正需通过来源关系更新局部几何，本轮暂不联合优化位姿。

## 4. 执行顺序和预算

### G0：已有产物机制审计，不新建图

固定开发场景 **SceneNN 014、Replica office_0**；它们均已暴露。对两场景的全部对象做 merge/fragment/contamination 分解，保留成功、失败和未触发对象。先检查原观测是否包含可分信息；已有 GT 只用于错误归因与理想重分配上界，不进入推理。

若错误主要来自没有检测到的对象、没有测到的表面，或有信息的误合并不足以改变实例指标，则停止当前拆分假设，不靠人工注入错误制造主结果。可控注入只作为另报的机制测试。

### G1：有限的机制比较和拆分开发

复用上述两场景缓存和已有 baseline、SOR、Ours；最多新增 **10 个完整场景输出**：

| 新增方法 | 两场景输出数 | 要回答的问题 |
|---|---:|---|
| 固定归属 simple ratio | 2 | 普通多视图比例过滤是否已经足够 |
| 固定归属 MaskClustering-style filter | 2 | 既有点过滤的分母/可见性定义是否解释收益 |
| 普通几何二分 | 2 | 收益是否仅来自空间聚类 |
| 多视图拆分，无独立视角验收 | 2 | 提案本身是否已经解释全部收益 |
| 相同提案 + 分离视角验收 | 2 | 验收机制是否减少误拆分并保留恢复能力 |

阈值、帧块、提案数和复杂度惩罚在查看本轮输出分数前写入可执行协议并哈希冻结。最多另允许 2 个因已定位实现错误而重跑的输出，总预算 12；保留被替换记录，不做参数搜索。此文档给出预算和验收结构，尚不是实现参数已冻结的实验注册。

过滤对照固定源点、对象归属、输入掩码、语义与 final processing；不得把 MaskClustering 的拆分及对象删除偷偷加进“点过滤”臂。不同证据分母的定义逐项列出。删点精度/召回和保留量曲线作为诊断；利用 GT 选取曲线最佳点不得成为主结果。

拆分臂固定同一提案集合、同一来源几何和重建过程，只有接受机制变化。用相同最近点投影评测完整地图，报告 PQ、RQ、TP/FP/FN、恢复/丢失匹配、误合并/误拆分数、每对象变化，以及耗时与内存。对象级诊断不把同场景多个对象当作独立样本。

继续门槛：两个开发场景都实际恢复至少一个原先因误合并未匹配的 GT 实例；每场景原有正确匹配不减少；完整地图 PQ 均不下降；分离视角验收较无验收臂减少错误拆分且保留至少同样多的恢复实例。还应对普通几何拆分有明确的精度/恢复收益，不能只与旧删点方法比较。若收益仅来自切换评估器或验证模块消融无差异，不把该机制写成核心贡献。

这些是开发筛选条件，不是统计显著性、创新性或录用保证。已使用的四个 SceneNN 场景也不能再充当新方法完全未见的测试集。

### P0：一段车库的真实修订

首选 rosbag2245；先核验图像、位姿、点云、外参、坐标修订及时间同步。稀疏 LiDAR 未命中的像素是未知，不能当作自由空间或反驳证据。

在同一输入上比较原地图、SOR、当前 visibility1。取得独立于被评测方法的参考：预先固定空间区域/对象范围，完成盲于方法结果的人工实例标注或独立高质量参考重建；记录标注范围和不确定区域。若只有二维标注，只报告对应的二维一致性，不能称为三维 PQ 真值。

先交付完整场景前后图、全量对象得失、覆盖率及独立模块计时。没有参考前不宣称量化准确率提升。拆分模块通过 G1 后再加入同一重放流程。无需等待 S100 SSH；离线 rosbag 回放与实机在线验证分别标注。

### P1：通过 G1 后才扩大

- 外部独立测试：先审计项目数据暴露记录。目前记录显示本地 8 个 Replica 场景均已查看，因此优先获取未用 ScanNet 场景，或其他真正未用数据；不得把现有 Replica 重命名为独立集。依许可获取，冻结场景清单后再运行。
- 鲁棒性：分别测试位姿扰动、深度缺失/噪声、mask 边界偏移；包含未扰动输入。单位、幅值、随机种子和重复次数预先固定，各方法用相同扰动。对稀疏 LiDAR 另报告有效证据覆盖，避免把 dense RGB-D 门限直接泛化。
- 运行代价：在固定硬件与线程数下分开测 kernel、提案、验收、I/O；预热后重复测量中位数和分位数。前端及定位耗时独立报告，不由旧 cleanup 总时长推断实时性。

## 5. 文献与贡献审查

- [Point-Level Refinable Semantic Mapping](https://arxiv.org/abs/2610.31476v1)：已有点级置信度修订；必须避免以“在线可见性更新”重复主张创新。
- [VOIM](https://arxiv.org/html/2609.00775v1)：已有延迟决策和体素证据累积；新机制需区别于普通软投票。
- [OASIS-Map](https://arxiv.org/abs/2607.14899v1)：已有跨访问密集对应；接入 DINO 本身不构成差异。
- [MaskClustering 官方实现](https://github.com/PKU-EPIC/MaskClustering/blob/eb2d41c2267cde21966f4340c37b8cf94b05c23c/utils/post_process.py)：直接检查点比例过滤与拆分，优先做同条件机制对照。

新论文是否成立，以“哪些旧错误被恢复、为何普通方法恢复不了、代价多大”为依据；不以增加一个模块、改标题或只挑一张成功图作为验收。
