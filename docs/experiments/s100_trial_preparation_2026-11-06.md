# S100 试跑工程准备与本地验证

本轮完成可选在线语义链路和源码打包，未连接或部署到机器狗。目标架构为 S100 运行 LIVO、配套电脑运行语义推理；S100 BPU 转换和性能验证尚未进行。[部署说明](../deployment/s100_livo_semantic_trial.md)给出编译、输入检查、启动、RViz 和录包步骤。

## 变化

- 新增 `LivoSemanticFrame`，将同一关键帧的点云、位姿、原始采样时间的校正图像、内参和相机时刻补偿变换一起发送。原有关键帧消息不变；增加独立 best-effort topic，推理不在估计器进程运行。
- `semantic_trial` 使用本地 Mask R-CNN 与可选 SegFormer，发布实测范围三维框、短时行人框、验证后的地面点和标注图。持久对象、位姿和证据落盘。
- 队列保留最新待处理帧，拒绝错误时间/坐标契约与会话重启混用；限制短程试跑规模；断流及故障通过状态输出呈现。状态与处理调度使用独立稳态时钟，回放 `/clock` 停止后仍可报告状态。
- 新增只读输入审计、RViz 配置、原生构建和源码打包脚本。保留既有默认 LIO 部署与全部离线实验数据。

## 实测

本机 x86、ROS 2 Humble 编译 `omni_slam_interfaces`、`fast_livo`、`omni_semantic_map` 通过。语义单元测试 11 项通过，涵盖重投影、关联、地面坡度/墙面拒绝、稀疏/混合深度拒绝和最新帧队列。本环境有既存 SciPy/NumPy 版本范围警告；未修改系统依赖，测试与本轮推理仍通过。正式部署应使用匹配的依赖环境。

用既有 `rosbag2245` 30 秒准备包，以 0.5 倍速运行原生 ROS LIVO，并启动真实模型的独立语义节点，结果保存在 `build/experiments/s100_trial_20261106/replay_v3/`：

| 检查 | 结果 |
| --- | --- |
| 语义收到并处理的关键帧 | 12 / 12，待处理替换 0，拒绝 0 |
| 静态对象记录 | 9 条车辆记录，其中 1 条满足重复观测门槛；不是车辆真值数量 |
| 静态框消息 | 12 条，累计含 40 个线框（包含同一目标的重复发布） |
| 地面消息 | 12 条，合计 75 个通过几何验证的点，未证明地面覆盖充分 |
| 本机单帧处理耗时 | 最小 1.105 s，中位 1.141 s，最大 1.234 s；不是 S100 性能 |
| 最后结果年龄 | 0.628 s，采用 0.5 倍速仿真时间，不能视为实机端到端延迟 |
| 输入停止 | 正确报告 `no_recent_visual_keyframes` |
| 运行状态 | 未进入 `error` 或 `session_mismatch` |

独立探针收到 5 个 best-effort 原子包并核查时间/图像/点云契约；这不是全部关键帧接收率。保存的前三个包约 836 KB/包。语义节点本身收到 12 帧；网络、DDS 分片与订阅处理的丢包需要现场继续测量。原生归档有 17 个关键帧，语义只处理有效视觉输入，不保证每个归档帧都进入语义节点。

真实输入包进一步用于故障契约测试：错误图像时间被拒绝；两个待处理输入只保留最新一个；ID 回退进入 `session_mismatch` 并清空待处理队列。这项测试使用模型替身隔离生命周期逻辑；上面的 ROS 回放使用真实模型。

回放期间发现并修复了新增图像导出误用 COLMAP 可选指针的问题，以及仿真时间未开始时状态定时器无法运行的问题。最终回放和契约测试均通过，早期失败日志保留在 `replay/`、`replay_v2/`。

## 验证入口

```bash
PYTHONPATH=omni_semantic_map python3 -m pytest omni_semantic_map/test -q
# source 对应 ROS overlay，使用隔离 DDS 域后：
python3 FAST_LIVO2/test/check_semantic_trial.py --help
python3 FAST_LIVO2/test/check_semantic_contracts.py /path/to/packet_1.cdr
```

`replay_v3/validation.json` 保存完整计数，`semantic/frames.jsonl` 保存逐帧时延和支撑观测。模型、图像证据和当前三维结果均来自实际录包，不是合成输出。
