## 1. 从诊断到完整地图

上一轮局部表面传递未通过筛选，本轮没有继续调其几何阈值。先核查已缓存的19类SAM3响应，再加入一个独立的、有监督外部分割对照。

原19类SAM3是不同文本查询下的原生检测分数最大值，**不能直接解释为可跨类别比较的校准后验**。在全部47/36个原对象的源点来源上，均值响应指出的类别污染，0000中只有2.65%确为污染，0002为87.87%。这些数字是原始源点语义诊断，不是融合地图实例精度。

外部模型使用[NVIDIA SegFormer-B5 Cityscapes权重](https://huggingface.co/nvidia/segformer-b5-finetuned-cityscapes-1024-1024)，参考[官方实现](https://github.com/NVlabs/SegFormer)。固定版本为`2c6f153e4c23c229e2fa2b188eb250607e030cd8`，约339MB权重，官方LFS SHA256为`bdefc7b5bf4b548d347e6bcbe3ab1a0ff4370047211ae9e56c9e53dfb1f78033`。严格加载，无缺失或多余参数。

108个原图各一次FP32前向；原配置1024×1024预处理，原图尺寸双线性恢复logits后softmax。保存原生低分辨率logits、完整类别图、原实测可见源点概率，以及通过原5厘米实测深度门槛的融合地图点概率。没有微调、换模型、额外裁剪、多尺度或置信度搜索。

外部模型源点均值读出的污染检出精度为11.08%/84.42%，并非两个窗口都更好。两模型均有误判，因此本轮继续到完整地图，避免用逐点指标代替主线验收。所有108帧封存后才作新增GT诊断。

该模型使用Cityscapes监督，不能称为我们的创新、开放词汇模型、无标注系统或KITTI-360官方方法复现。

## 2. 候选机制的精确定义

地图由原融合点集合 \(M\) 及固定对象ID、类别、排序分数组成。测量域 \(Q\) 为实际观测到且具有共同语义概率的原始实测源点；无观测处没有损失项。

每个20厘米物理单元总权重为1，其内源点均分。语义分布保留地图已有类别（本轮为building/car），其余19类概率之和构成“无被跟踪类别”事件 \(\bot\)。它不是未知观测，也不以新背景点的方式插入地图。

用严格20厘米范围内最近存活地图点的类别作为读出，等距按原始点索引裁决：

\[
E(M)=\sum_{q\in Q}w_q[-\log\max(p_q(c_M(q)),10^{-8})].
\]

没有附近地图点时，\(c_M(q)=\bot\)。该损失度量的是外部模型与地图的语义一致性，不是GT误差、实例IoU或校准后的实际风险。

候选区域来自具有旧对象点的20厘米单元：单元内所有已观测源点的平均19类分布，若唯一最大类不同于旧对象类别则提出该单元。按对象分别取26邻域连通分量，区域包含该对象在这些单元内的全部原地图点。按点数递减、对象ID和空间键固定顺序，最多500区域/窗口；实际为386/379，全部进入对照。

对于拟删除区域 \(R\)，只有当前最近地图点属于 \(R\) 的查询位置可能改变读出。精确重新查找这些位置在删除后的最近存活点，可由其他对象接管，也可能回退为 \(\bot\)。**Ours仅当全部受影响实测位置的损失严格降低超过数值容差\(10^{-9}\)时原子提交。** 逐区域更新当前地图与读出，最后与完整重算逐点核验一致。

这区别于逐点语义筛选：删除冗余点可能不改变任何预测；删除整个区域则可能影响相邻单元，甚至让其他对象接管。它也区别于上一轮空间监督：本轮直接修改历史地图几何，使用共同外部模型证据，没有训练接受器或把旧地图当作永远不可修改的前缀。

边界明确：只有点删除，没有新点、新对象、对象ID合并/拆分或保留点重标。目标只区分类别，无法识别同类实例之间的错误接管；损失下降不保证实例地图变好。普通语义模型、连通分量、最近点读出和贪心更新本身都不是首次提出的贡献。

## 3. 对照与不变量

| 条件 | 实际行为 |
|---|---|
| Frozen strong baseline | 原`geometry_graph`逐字节副本 |
| SegFormer + point filter | 删除直接实测投影均值预测为其他类的原地图点；缺测/平局保留 |
| SegFormer + region filter | 删除共同候选池内全部区域，无反事实检查 |
| Local counterfactual | 同候选、顺序和实际前后读出，仅在区域单元内计算接受收益 |
| **Ours — counterfactual revision** | 同候选、顺序和读出，在全部受影响实测位置计算接受收益 |

除原基线外，共享同一次外部模型输出。类别、排序分数、原坐标和保留点的对象ID不变，没有额外NMS、SOR、稠密补点或其他后处理。新几何文件保存`retained_base_indices`，不沿用已失效的追加点尾部索引。

原始源点与融合点分开读出；缺测不作为背景。参考类别来自原始taxonomy，`trainId=0`的道路有效，`255`忽略。原始语义诊断使用20厘米最近参考转移；不能将它说成逐像素人工真值。

7项测试覆盖：冗余点与联合区域、局部改善损害邻域、零权重不授权修改、其他存活类别接管、顺序更新完整重算一致、平局与距离边界、连通候选顺序一致性。首次测试发现新文件放置层级错误，移到实际Python包后通过；未产生实验地图。

## 6. 预算、执行与去留

外部模型采集108帧耗时约29.26秒，PyTorch峰值分配2.06GiB；不含加载和后续CPU建图/评分。所有新地图完整封存后评分，没有看到部分窗口得分再改另一窗口的配置。

原规范类别名的检查在推理前发现KITTI-360有`garage/gate/smallpole`等别名共享训练ID，已改为按原taxonomy首个规范名称核对，原协议和源文件快照保留。仅修正元数据核查，没有更换模型、帧或推理参数。产物审计首次JSON序列化遇到NumPy整数，转换为Python整数后重算同一审计；模型、地图、分数均未重跑。

预设门槛要求：两个窗口不低于基线，均值至少提升1个百分点并超过全部对照，新增至少1个AP50正确匹配且无丢失。本轮只有0.433个百分点、与简单对照同分、0新增1丢失，因此关闭此固定版本，不扫区域尺度、置信度、损失、顺序或迭代次数。

**主线去留：**保留共同外部语义输入和结果作为已测对照，不升级为已验证创新或生产主线。研究目标仍是完整对象地图质量。后续方案必须解释怎样恢复缺失或未正确识别的对象、怎样避免损害原有正确对象；不能继续用语义自洽或车辆高IoU的小幅变化代替实例建图贡献。当前删除式实现无法生成新对象或补全缺失表面，这一能力限制不能靠改损失名称解决。

有效新机制、同版本机器人对照、新增独立评测仍未完成；总目标保持进行中。
