# 对象来源记忆：完整地图对照与主线决定

主线是 **omni_slam 持续对象级语义建图**，LIVO 提供定位与实测几何。研究目标是完整对象地图的准确性、完整性和身份一致性；有效机制需要公开 benchmark 强对照、消融、独立评测及同版本机器人验证。模型接入与局部点级指标不替代这个目标。

[图文报告](../../output/provenance_object_memory_v1/index.html)包含真实室外 RGB、完整地图、八条训练曲线、全部三个新增/丢失匹配的可视化以及全部 94 个合格 GT 的逐对象结果。

## 本轮方法与边界

保留强基线对象 ID，为每个对象保存来源可追溯的逐帧观测，使用冻结 VGGT 描述子、实测几何和 SegFormer 类别证据，学习旧点保留/移除/改归属及新实测点接纳。对照包括均匀池化、描述子检索、全视图注意力、同权重仅追加和 Ours 历史修订。

所有学习条件使用共同候选覆盖和相同网络容量。Ours 只读取与查询不共享四帧 VGGT 图像上下文的历史视图；这不代表统计独立。均匀池化作用于学习后的逐视图证据，并非直接平均原始特征。仅追加条件与 Ours 的决策数组完全相同，区别是是否提交旧几何修改。

这是窗口末端离线修订：对象 ID 来自上游完整窗口，不宣称在线身份发现；没有新对象出生、合并或拆分。因而尚未覆盖主线要求的完整对象形成能力。

## 核查与解释

完成八次固定 40 轮训练、十二份完整地图和五项核心测试。818 条对象视图记录、245300 次来源观测重放通过，全部候选可用性与来源坐标核对通过；描述子相似度抽查 11220 项。地图重放确认未质疑旧点保持不变、仅追加与修订共享决策、原强基线文件保持一致。

不同条件确实改变了决策与地图，不是重复缓存。显式对象来源记录避免了上一版匿名槽位相互坍缩的问题，但这只是实现性质，不能证明身份正确或方法创新。

与候选集合训练目标的一致率从基线 81.26%／73.52% 提高到 Ours 87.34%／84.58%，完整地图平均 AP 却下降。该一致率只覆盖可评估候选；无 GT 对应候选时目标可能为 null，不能解释为全场景语义准确率。现有证据支持进一步检查训练目标与地图质量的关系，但尚不能把退化唯一归因于损失函数，也不能据此自动追加训练。

## 去留决定

本版本封存，强基线继续保留；不追加阈值、轮数或随机种子搜索，不将失败版本扩展到机器人和独立场景。有效新机制、同版本机器人验证及新增独立评测仍未完成。

后续候选须先说明它如何改善完整对象形成或修订、当前证据支持哪个机制缺口、同输入简单方法为何不能解决，以及有限预算下的完整地图验收条件。已有 0000/0002/0003/0004/0005 均不作为新独立测试。主线交付仍是可验证的对象地图收益及论文证据链。

原始产物：`build/benchmarks/provenance_object_memory_v1/`；冻结协议 `protocol.json`，预测封存 `predictions_complete.json`，输入审计 `input_audit.json`，地图审计 `map_audit.json`，评分 `summary.json`。
