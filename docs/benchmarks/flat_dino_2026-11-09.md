# 冻结 DINO 与可撤销对象关联：首轮 Flat 实验

2026-11-09。**本轮没有获得稳定的地图精度收益。** 冻结 DINOv2 平均/局部特征已接入，两个完整序列各运行六种配置；另输出两种图方法的最终修正评分。可撤销证据图的机制与回归检查完成，但不是论文已验证方法，也没有训练新的关联 Transformer。

## 环境与输入

- 宿主机为两张 NVIDIA RTX 5090，每张 32,607 MiB；驱动 570.153.02，CUDA 12.8，PyTorch `2.12.0.dev20260317+cu128`。最初沙箱内 GPU 查询失败，升级到宿主机执行后两张卡均通过 CUDA 运算检查，run1 使用 cuda:0、run2 使用 cuda:1。未修改驱动，未停止其他 GPU 任务。
- 模型为 [facebook/dinov2-small](https://huggingface.co/facebook/dinov2-small)，固定 revision `ed25f3a31f01632728cabb09d1542f84ab7b0056`。权重 SHA256 `ae1e99fcefd534ed978cdeb8326f08030c96e28b7a81ffcbc98a857c84d14be1`；冻结权重、eval、无训练。
- 保留完整视野，RGB 双三次缩放为 448×336，ImageNet 归一化，提取 24×32 个 patch 特征。不使用默认中心裁剪。平均描述子按有效深度掩码内支持点数加权；每个观测最多保留 24 个局部特征及其相机坐标支持位置。小目标不丢弃，但边界 patch 仍可能混入背景。
- Flat run1 400 帧、run2 362 帧全部参与。提供位姿、Detectron 掩码、深度门限及 4 像素采样步长与上一轮固定输入相同；从旧几何基线的观测支持点构造缓存，去掉旧对象 ID。GT 只在事后独立评价函数与诊断脚本中读取。
- GPU 提特征循环耗时分别约 6.70 / 6.70 秒，不含模型加载和输入哈希验证，不能当作端到端实时建图速度。CPU/GPU 描述子平均余弦约为 1，最大逐元素差异小于 1.7e-6。缓存和权重哈希均保留。

## 方法与预先固定参数

几何、HSV、DINO 平均、DINO 局部四组共用类别约束、1 m 中心距离门限和 Hungarian 一对一分配。外观只作为加性代价，权重 0.6，没有外观硬拒绝或歧义拒绝。因此这里的 HSV 不是旧版含拒绝规则的 omni_slam。

DINO 局部记忆保存最多 8 个历史视图，每个最多 24 个 token；在世界坐标下找 0.20 m 内的最近支持点，至少 3 个有效匹配才用局部余弦距离，否则回退到对象平均描述子。视图用均匀历史索引选择，未实现学习式视角选择。**这只是空间重叠条件，不是完整的深度遮挡/可见性推理。**

图方法保存全部不可变观测，在 1 m 内取最多 12 个历史观测候选。至少 3 个局部支持匹配、总代价不大于 0.55 时建立边，按代价排序合并分量；同帧两个不同检测不能进入同一分量。新证据可以改变旧分量，位姿修改会重建候选及边，允许拆开错误融合。每次修正都记录观测 ID、旧归属和新归属。该同帧约束假定检测掩码对应不同对象，可能妨碍修复检测器过分割；没有实现概率多假设或运动物体模型。

首批配置在读成绩前固定，[协议](../reports/flat_dino_2026-11-09/provenance/protocol.json)。看到图方法减少误合并后，追加仅将外观权重置零的图消融，其他规则一致；这是明确的事后开发消融，[追加协议](../reports/flat_dino_2026-11-09/provenance/graph_ablation_protocol.json)。其运行 `method` 字段仍为 `dino_graph`，以 `config.appearance_weight=0` 和 `geometry_graph` 输出目录区分。

所有分数为 PQ×100，越高越好，忽略类别。序列像素按整段有效深度支持累计；观察体素按相同 5 cm 世界体素多数投票，包含未预测的 0 标签。均为开发诊断，**不是官方 ScanNet AP，也不是完整场景 TSDF/实例重建成绩**。未重新调参寻找更好结果。

## 为什么评分相同不代表特征没起作用

与几何基线比较，DINO 平均特征在 run1/run2 分别改变 33/31 帧的实例图，局部记忆改变 81/32 帧。数字 ID 变化可能包含重命名，因此另统计不依赖 ID 编号的观测对分区差异：平均特征为 6,585/1,474 对，局部记忆为 10,490/1,337 对，说明实际分组发生变化。

在几何基线的历史状态下，run1 有 905/1,636 个观测存在多个同类空间候选，run2 为 398/1,144。不能将无收益简单解释为“没有关联歧义”。局部匹配回退比例约 49.6%/54.5%，稀疏 token 的空间重叠不足是值得继续分析的限制，但尚未证明是唯一原因。[决策审计](../reports/flat_dino_2026-11-09/provenance/decision_audit.json)。

## 事后身份诊断：减少误合并的代价

只在检测支持点中，选真值实例占比至少 70% 且为 thing 的观测，run1 为 1,494/1,636 个（覆盖 33 个 GT 实例），run2 为 1,037/1,144 个（32 个 GT 实例）。在这个固定子集计算同对象观测对 precision / recall / F1，包含同帧对，未计入未检测对象；不是整体检测召回或主指标替代品。

| 方法 | run1 P / R / F1（%） | run2 P / R / F1（%） |
| --- | ---: | ---: |
| 几何 Hungarian | 92.73 / 28.14 / 43.17 | 96.06 / 53.66 / 68.85 |
| 几何＋HSV（无外观硬门限） | 92.74 / 27.97 / 42.98 | 96.19 / 54.01 / 69.18 |
| 几何＋DINO 平均特征 | 92.67 / 28.11 / 43.13 | 95.60 / 53.68 / 68.76 |
| 几何＋DINO 局部记忆 | 92.79 / 26.78 / 41.56 | 96.32 / 53.76 / 69.01 |
| DINO 图：因果输出 | 99.97 / 30.70 / 46.97 | 100.00 / 45.91 / 62.93 |
| 无外观图：因果输出 | 99.98 / 30.93 / 47.24 | 100.00 / 47.01 / 63.95 |
| DINO 图：最终修正 | 100.00 / 31.91 / 48.38 | 100.00 / 53.92 / 70.07 |
| 无外观图：最终修正 | 100.00 / 32.11 / 48.61 | 100.00 / 55.66 / 71.52 |

DINO 图最终归属在该子集没有混合不同 GT 的记录，但仍有 20/16 个 GT 实例被拆分；几何基线为 19/15 个。因此“观测对 precision=100%”不能解释为地图正确率 100%。图方法的保守连接和同帧冲突约束可以减少误合并，却仍难跨越不重叠视角，片段数量及主指标没有同步改善。[完整身份诊断](../reports/flat_dino_2026-11-09/provenance/identity_pair_audit.json)。

## 下一步研究判断

这轮证明接入与机制可以运行，尚未证明新的算法优势。下一轮应先定位“不重叠视角导致的碎片”和“检测过分割与同帧约束冲突”，设计明确的对应/可见性证据。训练关联 Transformer 前，需要独立训练数据和未用于调参的评价场景；不应在 Flat 两段上训练后再用同两段宣称泛化。当前没有训练 Transformer、没有接入实际在线回环、没有改动部署默认关联规则。
