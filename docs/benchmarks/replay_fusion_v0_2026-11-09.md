# omni_slam 融合初版：特征诊断与位姿修正回放

2026-11-09。已得到可运行的研究初版、8 场景交叉对照、受控位姿修正实验和论文初稿。对象关联/融合沿用 ConceptGraphs 官方核心；omni_slam 新增不可改写的观测记录、历史输出隔离、事务式位姿重放及对象证据导出。**该初版达到所接入核心的精度，不代表我们提出了超过 ConceptGraphs 的新方法。**

## 这轮回答了什么

八个开发场景均值：旧 competitive 图为 14.945；相同图框架改用池化 DINO/CLIP 为 15.078/15.187；原生对象融合用 DINO/CLIP 为 18.712/19.628。单换特征不能解释主要差距，下一步应把研究重心放到对象融合和可修正身份。

所有场景已在此前查看。本轮每场景固定 200 帧（0、10、…、1990），不得称为新的独立测试。指标是相同观察表面的 5 cm 类无关实例 PQ×100，不是官方 Replica 网格 AP。原生映射仍使用共享 Mask R-CNN 和稀疏深度输入，不是原版 GSA 前端端到端复现。

## 特征与映射交叉对照

图框架保留几何候选、局部支持数量、共视/归属约束，只将局部 token 特征替换为重复的池化向量。原生融合只替换图像向量，最终合并使用的 CLIP 文本向量保持不变。DINO 为掩码内 token 池化，CLIP 为框裁剪编码；这是表示方案对照，不能把差异全部归于编码器架构。所有原有阈值固定，没有按特征或场景重新调参。

## 初版实现与位姿回放

入口为 `omni_semantic_map.replay_fusion` 和 `omni_semantic_map.fusion_benchmark`。每个观测保存关键帧、实测相机坐标点、颜色、图像/文本特征和 ID。对象保存其观测成员与当前世界坐标点云/包围盒。原始观测与历史因果输出分开保留；收到完整修正位姿表后，在新后端上重放，成功后一次性发布新版本，失败时保留旧状态。最终过滤/合并在快照上执行，不污染随后继续接收观测的在线状态。

全量重放是初版的正确性基准，不是增量算法或创新主张；目前没有自动把旧可见性否决拼接到该后端，也没有宣称其提升了原生核心精度。后续若做局部重算，必须和这个全量参考结果比较。

受控实验在运行前固定：每帧左乘从零增长到 X 平移 0.2 m、绕 Z 旋转 3° 的位姿扰动，随后恢复数据集提供位姿。冻结身份的对照与重放方案都用修正后的原始测量支持评价，因此比较的是身份重划分收益；不是在原始漂移点云上比较几何误差。

| 场景 | 冻结漂移后的身份 | 修正后重放 | 干净原生参考 | 全量修正重放 s |
| --- | ---: | ---: | ---: | ---: |
| office_0 | 12.130 | 16.666 | 16.666 | 5.24 |
| room_1 | 2.591 | 7.288 | 7.288 | 2.15 |
| office_1 | 17.242 | 18.276 | 18.276 | 5.06 |
| room_2 | 25.843 | 34.142 | 34.142 | 3.18 |
| office_2 | 15.855 | 16.544 | 16.544 | 4.84 |
| office_3 | 16.182 | 20.189 | 20.189 | 6.45 |
| office_4 | 18.235 | 22.829 | 22.829 | 5.69 |
| room_0 | 21.747 | 21.087 | 21.087 | 3.66 |
| 均值 | 16.228 | 19.628 | 19.628 | — |

恢复平均 PQ 为 16.228→19.628，七升一降。room_0 为 21.747→21.087：恢复干净算法状态并不保证更高 GT 精度，原生核心的过合并也会被重放复现。

![受控恢复](../reports/replay_fusion_v0_2026-11-09/recovery.png)

八场景均验证：干净原生参考的因果/最终标签逐项一致；修正后身份、点云、颜色、包围盒、图像/文本特征与干净重放一致；恢复扰动位姿后回到原划分；历史因果输出未改写。几何数组比较容差为 1e-10。这里的恢复依赖提供正确位姿，不是位姿估计算法，也不是实际 LIVO 回环准确率实验。

![office_0 身份恢复示意](../reports/replay_fusion_v0_2026-11-09/recovery_map.png)

耗时是同机单次 CPU 重放、缓存特征条件下测量，有并发负载；未计检测/特征提取，未测 S100，不能解释为板载实时性能。

## 初版验收与下一轮

58 项测试通过，包括原有语义模块，以及输入证据隔离、非法/失败修正不发布、失败输入回滚、实际原生融合的合并/拆分恢复、拒绝观测保留和随机状态隔离。整场适配暴露的只读数组布局问题及 uint16 像素排序溢出均已修正；失败日志和修正前后的源码哈希保留在协议中，未忽略因果标签不一致。NumPy/SciPy 版本声明警告仍存在。

今天的可交付物是研究初版和可复现实验，不是可投稿的新颖性结论。[论文初稿](../paper/omni_slam_v0_2026-11-09.md)明确区分借用组件、已验证能力及待验证主张。下一轮优先研究有证据约束的局部撤销/重融合，并用全量重放作正确性参考；真实估计位姿、新的独立场景、标准实例评测与增量成本仍需补齐。

## 复现与文件位置

新增代码在仓库 `omni_semantic_map/omni_semantic_map/`；原始实验目录为 `build/benchmarks/replay_fusion_20261109/`。`replay_runs/<scene>/objects.pkl.gz` 保存修正后的原生世界点云、3D 包围盒、特征及成员观测，`events.json` 保存身份变化，`pose_protocol.npz` 保存实际使用的两套位姿。

[全部指标、图表、审计和源码快照](../reports/replay_fusion_v0_2026-11-09/)。官方源码、模型及环境沿用[上一轮固定版本](expanded_semantic_2026-11-09.md)，原生仓库未修改。当前环境已配置，重跑选择新的输出目录，已有目录会拒绝覆盖：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
PYTHONPATH=omni_semantic_map:build/benchmarks/expanded_semantic_20261109/concept-graphs \
  build/benchmarks/expanded_semantic_20261109/cg_venv/bin/python \
  -m omni_semantic_map.fusion_benchmark replay \
  --source build/benchmarks/expanded_semantic_20261109 \
  --output build/benchmarks/replay_fusion_v0_rerun \
  --scene office_0
```

图框架对照把 `replay` 换成 `graph`。完整原生 CLIP/DINO 阶段消融、评分和报告脚本保存在附件 `provenance/tools/`；这些批处理脚本使用本次固定根目录。复跑时须改成新根目录，不能覆盖原始证据。
