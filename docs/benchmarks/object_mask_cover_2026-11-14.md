# 完整实测表面的多掩码解释与历史修订

日期：2026-11-14。项目：omni_slam。

## 实验问题

上一轮确认类别计数目标会偏好错误碎片。本轮直接实现新的对象候选与解释模块：先从实测几何中形成连续表面，再允许多个局部掩码共同解释一个表面。目标是检验它能否形成遗漏对象、减少虚假实例，并在有直接证据的区域修订历史归属。

这是一次固定配置的完整地图实验。两个 KITTI360 窗口均已暴露于开发，不是独立测试或官方榜单；旧强基线和失败的类别计数分支保持冻结。

## 实现

1. 复用完整实测来源、20cm 单元与严格小于 0.4m 的 16 近邻同类局部边。每个连通分量成为一个完整候选表面，不再使用类别 token 目标拆分，也不使用非局部查询链合并。因此，本版不能跨几何间隙合并断开的表面。
2. 在原有可见性记录中，读取所有正分同类原生 SAM3 掩码。每个可见三维单元分配总质量 1，由该单元当前可见来源点均分。**对象外的其他类别和未知测量点也参与泄漏计算**；未观测空间不投票。
3. 单帧解释效用为：掩码并集覆盖的对象内质量，减去对象外质量，再减去选用查询的成本。查询成本固定为 `log2(1+Q) - log2(native_score)`。同一位置重复覆盖只计一次。贪心加入效用增益大于 `1e-10` 的掩码，停止后不再搜索其他权重。
4. 汇总对象的视图解释效用；累计效用大于 `log2(几何分量数+1)`，且至少 3 帧有正效用，才接纳对象。此处是固定覆盖效用模型，**不是校准后验、严格无损 MDL 编码、全局最优集合覆盖或已证明的新贡献**。3 帧不是独立观测保证。
5. 已接纳表面与旧 ID 通过同类、正重叠、最大重叠的一一匹配关联；不强制旧 ID 不可拆分或合并。无匹配表面继承公共出生条件：至少 16 个实测来源、至少 3 个原始掩码观测帧。旧类别与排序分数保持，新身份使用共同的原生观测分数。
6. 完整图保留全部旧坐标，追加点均来自实际 LiDAR 测量。历史点只有在其精确单元属于已接纳表面、且公共双帧传播认证与该表面的身份一致时，才允许修改归属。其他旧点保持原标签；未解释不等于背景。所有历史组共用此规则。

## 对照与冻结验收

| 方法 | 表面接纳 | 历史归属 |
|---|---|---|
| 当前强基线 | 原冻结地图 | 保留 |
| Geometry + history | 全部几何候选，继承共同出生条件 | 直接证据规则 |
| Single-mask explanation | 每帧最优单掩码 | 直接证据规则 |
| Union / current only | 每帧贪心多掩码并集 | 完全保留 |
| Ours candidate / union + history | 每帧贪心多掩码并集 | 直接证据规则 |

固定预算：两个窗口、8 份新地图输出、30 次完整评分（包括基线和两个诊断口径）。主指标沿用 AP50:90；原始目标身份和统一排序分数仅用于诊断。原先类别计数分支的历史导出会改写更多传播位置，本次范围更严格，因此不能用两个分支的差值单独归因于多掩码；本轮内部控制共用新导出规则。

Ours 必须在每窗口主 AP/AP50 均不低于强基线、平均主 AP 至少提高 1 个百分点，且超过纯几何、单掩码和禁止历史改写三项控制；原始目标身份新增至少一个 AP50 正确匹配且没有丢失旧匹配，并实际修改历史点。任一条件不满足即关闭本配置，不改门槛，不搜索覆盖成本、半径或帧数。

## 观测层结果

0000 的 47,761 个原子单元形成 2,932 个几何分量，单/多掩码均接纳 55 个。0002 的 54,683 个单元形成 3,835 个分量，单/多均接纳 39 个。多掩码在 35/23 次区域—帧解释中增加了效用，但没有改变任何分量的最终接纳状态。因此多掩码的局部效用改善不能主张独立完整地图收益。

## 完整地图结果与决定

**冻结开发门槛为 false，本版封存，不替换强基线。** 下表为两个开发窗口的平均 AP50:90（%），不是 PQ。

| 方法 | 原主指标 | 原始目标身份诊断 | 统一置信分数诊断 |
|---|---:|---:|---:|
| 当前强基线 | **28.011884** | 27.995667 | **30.200009** |
| Geometry + history | 19.595094 | 20.096504 | 26.721590 |
| Single-mask explanation | 26.286587 | 26.366884 | 29.017975 |
| Union / current only | 27.985860 | **28.003739** | 30.173739 |
| Ours candidate / union + history | 26.286587 | 26.366884 | 29.017975 |

相对纯几何，整体掩码解释提高 **6.691493 个百分点**；相对当前强基线仍低 **1.725297 个百分点**。单/多掩码历史版的实际坐标、身份、类别与排序分数全部相同，这不是汇总时读错文件，而是 55/39 个接纳决策相同。**多掩码不能作为有独立增益的贡献。** 八份地图输出中包含这两组重复预测，不能称为八个不同方法的证据。

原始物理目标身份诊断中，Ours 新增 3 个建筑 AP50 正确匹配，同时丢失 3 个车辆匹配。所有对象完整列于报告，关键对象如下；IoU 为各方法最佳同类预测的独立诊断，不等同于置信排序后的 AP 匹配过程。

| 窗口 / 原始目标编码 | 类别 | 基线 IoU | 不改历史 IoU | Ours 历史修订 IoU |
|---|---|---:|---:|---:|
| 0000 / 2004 | 建筑 | 0.46550 | 0.56969 | 0.56969 |
| 0000 / 2005 | 建筑 | 0.33952 | 0.40568 | 0.57285 |
| 0002 / 2013 | 建筑 | 0.39424 | 0.54233 | 0.54517 |
| 0000 / 13021 | 车辆 | 0.79723 | 0.75656 | 0.48605 |
| 0000 / 13022 | 车辆 | 0.77864 | 0.78517 | 0.34365 |
| 0000 / 13024 | 车辆 | 0.52819 | 0.39366 | 0.39366 |

当前/历史消融中新增几何、身份和分数相同，仅旧点标签不同。建筑 2005 的恢复确实依赖历史归属修订，但车辆 13021/13022 同时因历史修订受损，最佳解释都落到旧预测 ID3；它们原来分别由 ID3/ID4 表达。车辆 13024 即使不改历史也已退步，说明新增点写入同样可能损伤旧对象，不能把问题全部归因于 ID 合并。以上不是“训练还不够”的证据，也不能只挑建筑涨点宣称整体有效。

Ours 两窗口追加 176,696/150,186 个实测点，生成 19/9 个新身份，修改 22,538/12,459 个历史点标签。新增正确匹配的三个建筑对应的最佳预测 ID 均已存在于强基线，主要是原对象几何/归属改善，不能把它们说成三次成功的新 ID 出生。

这轮留下的具体机制缺口是：**几何上连接的表面仍可能包含多个对象；整个表面获得掩码解释，不足以授权把其中的旧身份合成一个。** 同时，追加的实测点也会改变评测位置的归属。下一研究决策需要显式处理候选内部的身份竞争与写入影响；不得只换掩码数量、成本或支持帧数来挽救本版。该新决策尚未实现或通过实验，不能作为已完成贡献。

5 项核心测试通过；1,480 次解释使用原始掩码独立解包重算通过；8 份完整地图重放通过；6 次真实删除最大种子帧批次后，全部已认证标签保持不变。四张真实地图/RGB 图已查看。认证仅证明固定图的实现属性，不保证语义正确性。
