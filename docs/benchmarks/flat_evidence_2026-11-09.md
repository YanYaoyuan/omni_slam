# 共视冲突可撤销实验：收敛对象关联机制

2026-11-09。本轮新增 8 次完整运行（四种配置 × 两段），每次因果输出和最终修正地图独立评价。**首要失败源已从“特征不够强”收敛到共视约束与观测粒度冲突；多视角证据机制改善部分关联，但尚无稳定全局优势。**

## 失败审计与粒度问题

在 GT 纯度至少 70% 的已检测观测子集上，枚举属于同一 GT、却在旧严格 Graph 最终地图中分离的分量对。分层诊断中，共视冲突为 run1 的 320 对、run2 的 94 对；标签不一致为 44/55 对，稀疏支持不足为 24/5 对。原因可能重叠，计数不是因果贡献分解。

多数共视冲突集中于 `SM_Stack_of_Books_*`：Flat 将一摞书作为一个实例，而检测器可能输出多本书。不能把它们全部描述成“检测器错误”或泛化的对象跟踪失败。方法没有针对书类别的代码例外，主指标也未排除任何书堆。[全部失败审计](../reports/flat_evidence_2026-11-09/provenance/fragment_audit.json)。

## 本轮固定方法

继承前轮 Graph 的候选搜索、局部匹配和边代价，唯一研究变量为同帧掩码间的冲突处理：

1. **hard**：同帧两个检测永远不能进入同一对象。
2. **off**：完全取消这一约束，作为必须保留的强基线。
3. **witness**：只有两个掩码的实测表面相接，且至少两个空间分离视图中的观测分别与二者建立合格边时，才允许撤销冲突。
4. **witness_no_appearance**：同上，DINO 外观代价权重置零，隔离特征贡献。

表面接触：使用完整有效深度支持，两侧各至少 3 个点在 8 cm 内有邻点。独立视图：至少两个不同关键帧，选中相机中心两两距离至少 10 cm。其余门限沿用旧 Graph，不重新搜索。每个待合并分量之间的所有同帧冲突都必须通过检验。无监督训练，无 GT 参与关联，无类别特例。

观测与关键帧锚点保留，所有判断仅使用已到达观测。位姿修正后重新建立边和见证关系，原先获得支持的合并也可以撤销。没有新增定位前端或训练 Transformer。参数在新成绩产生前写入[协议](../reports/flat_evidence_2026-11-09/provenance/protocol.json)；但整个实验是在已观察 Flat 失败后进行，均为开发数据。

## 误合并与碎片的权衡

在前轮相同 GT 纯度子集上统计观测对 precision / recall / F1；run1 1,494 个观测、33 个 GT，run2 1,037 个观测、32 个 GT。不评价未检测物体的召回。

| 最终地图方法 | run1 P / R / F1（%） | run2 P / R / F1（%） |
| --- | ---: | ---: |
| 几何 Hungarian | 92.73 / 28.14 / 43.17 | 96.06 / 53.66 / 68.85 |
| 严格共视 Graph | 100.00 / 31.91 / 48.38 | 100.00 / 53.92 / 70.07 |
| 取消共视约束 | 75.09 / 90.93 / 82.25 | 98.26 / 86.26 / 91.87 |
| 证据修正共视约束 | 100.00 / 35.15 / 52.02 | 100.00 / 56.19 / 71.95 |
| 证据修正（无 DINO 代价） | 100.00 / 34.77 / 51.59 | 100.00 / 57.95 / 73.38 |

![精确率召回率权衡](../reports/flat_evidence_2026-11-09/precision_recall.png)

取消约束使 run1 观测对精确率降至约 75.1%，而证据修正仍为 100%；run2 取消约束的精确率仍较高，说明这一风险不是每个场景同样严重。100% 仅适用于这个已检测且 GT 纯度筛选的子集，不是地图正确率。

作为事后粒度敏感性分析，额外保留去除书堆观测的结果，但不替换主指标：run1 严格/取消/证据修正的 pair F1 为 78.89/85.67/79.02%；run2 为 86.94/86.13/86.94%。这说明证据修正当前收益很大程度集中于书堆粒度问题，需要独立场景检验其一般性。[完整身份审计](../reports/flat_evidence_2026-11-09/provenance/identity_audit.json)。

## 验证与研究决策

- 36 项语义测试通过，新增：一条见证不足、重复相机位置不算独立证据、表面不接触不能放松约束、位姿变化能撤销已获得支持的合并、硬约束与无约束对照。
- hard 组在两段共 762 帧的因果与最终实例图/有效域上，与旧 DINO Graph 逐值一致，控制组没有漂移。
- 所有原始输出保留，缓存与源码哈希固定；训练/推理环境保持原样，原有 NumPy/SciPy 声明版本警告仍存在。
- 当前实现可以支持“可修正共视约束”的机制讨论，尚不能支持论文主方法优于强基线的结论。本轮停止在 Flat 上继续调门限，不挑选更好结果隐藏无约束基线。
- 下一阶段只补两个关键证据：独立场景上精确率—召回率与地图质量的权衡；实际位姿修正时错误合并撤销的收益。DINO 作为可替换特征，不作为已证明的贡献。
