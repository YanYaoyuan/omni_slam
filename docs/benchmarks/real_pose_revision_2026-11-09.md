# omni_slam：真实 LIVO 位姿修正后的对象重划分

2026-11-09。两段真实录包、四种策略均完成。新的位姿进入后，重算候选边和约束得到的对象划分，与直接使用新位姿从头回放的结果完全一致；再切回旧位姿，原划分完全恢复。这里只验证工程一致性与可撤销性，**没有对象身份真值，不能声称修复了多少错误关联**。

## 输入和边界

使用已有归档中真实 LIVO / 离线位姿图优化前后的关键帧位姿，不人为添加位姿扰动。每段回放结束后一次性应用最终位姿更新，没有在线回环到达时序，因而不能解释为在线回环恢复延迟。

相机位姿采用 `T_world_camera = T_world_keyframe × inverse(T_camera_keyframe)`；后者包含原相机外参及图像实际时刻与关键帧时刻的运动补偿。观测支持点和局部 DINO 特征固定在图像相机坐标，更新位姿只改变世界坐标及关联关系。DINOv2-small、图边阈值和见证条件保持冻结。

| 输入 | 使用帧 | 使用观测 | 相机位置修正中位数 / 最大值 |
| --- | ---: | ---: | ---: |
| rosbag2245，车辆 | 181 | 328 | 0.444 / 1.971 m |
| rosbag2_20260415_162852，室外静态目标 | 440 | 251 | 0.255 / 0.806 m |

车辆输入沿用原检测框，使用原 Mask R-CNN 权重在保存的 JPEG 上恢复掩码及激光支持点。原 332 个观测中有 4 个恢复失败，记录在 `support_recovery.json`，本实验只使用其余 328 个；不能把这一输入描述成与原始未压缩图像完全相同。原 182 帧中一帧已有跳过标记。室外输入保留原静态检测，按原一秒激光融合窗口恢复支持点；动态行人不在此输入中。

车辆恢复支持的中位点与原观测中心距离：中位数 0 m、P95 0.097 m、最大 1.443 m。关联中心保留原记录，局部 token 来自恢复支持，因此个别观测中心与新支持存在偏差；这是输入恢复的限制，不能忽略。室外支持恢复中心差为 0。四种策略共用各自录包的同一缓存。

## 结果

“分离/连接”统计观测对的身份关系变化，不受对象编号重新命名影响；不代表正确/错误数量。对象总数相同也可能包含拆分和合并。

| 录包 | 策略 | 对象数：修正前→后 | 分离观测对 | 新连接观测对 | 单次修正计算耗时 |
| --- | --- | ---: | ---: | ---: | ---: |
| 2245 | 严格共视 | 211→211 | 4 | 85 | 81.5 ms |
| 2245 | 无共视约束 | 202→202 | 3 | 80 | 79.9 ms |
| 2245 | 证据修正 | 208→208 | 3 | 80 | 83.8 ms |
| 2245 | 证据修正，关闭外观代价 | 187→188 | 1 | 0 | 83.0 ms |
| 室外 | 严格共视 | 160→161 | 1 | 0 | 32.7 ms |
| 室外 | 无共视约束 | 160→161 | 1 | 0 | 33.4 ms |
| 室外 | 证据修正 | 160→161 | 1 | 0 | 32.9 ms |
| 室外 | 证据修正，关闭外观代价 | 160→161 | 1 | 0 | 31.8 ms |

全部 8 组均通过：新位姿重划分与新位姿完整回放逐元素一致；旧→新→旧往返恢复原划分。耗时为单次 CPU 关联重算，未计检测、特征、建图或磁盘读取，也不是重复测量后的实时性能结论。“仅移动对象”保留身份关系，因此按定义不会产生这些观测对变化；本轮未对其几何误差评分。

## 复现与证据

入口：[vbot_pose_revision.py](../../omni_semantic_map/omni_semantic_map/vbot_pose_revision.py)。原始配置、输入 SHA256、缓存、观测恢复失败和完整结果保存在 `build/benchmarks/real_pose_revision_20261109/`。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=omni_semantic_map \
  build/experiments/large_semantic_20261106/venv/bin/python \
  -m omni_semantic_map.vbot_pose_revision run \
  --cache build/benchmarks/real_pose_revision_20261109/cache/rosbag2245 \
  --output build/benchmarks/real_pose_revision_20261109/replay_new/rosbag2245
```

该结果补充“位姿修正会改变对象身份关系”的真实输入证据；论文仍需独立数据上的准确率优势及更接近的外部基线。
