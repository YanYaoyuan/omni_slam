# VGGT 完整采样序列建图评测 v1

本轮 6 张地图和统一评测均已完成，已复核全部输入、代码、特征及预测哈希，并重新计算六组 PQ 和 TP/FP/FN。目的是检验小窗口中的跨帧检索收益能否转化为完整对象地图的收益；不将未训练的对象记忆模块计入本轮方法。

## 完成结果

| 场景 / 实例 PQ × 100 | 原 SigLIP + history2 | VGGT 单帧 | VGGT 四帧联合 |
|---|---:|---:|---:|
| Replica office_0 | 30.92 | 33.38 | **33.54** |
| SceneNN 014 | 15.87 | **18.00** | 16.79 |
| 两场景均值 | 23.40 | **25.69（+2.29）** | 25.17（+1.77） |

三组总 TP 均为 24；FP 从基线 72 分别下降至 62 和 66。SceneNN 中两种 VGGT 都新增匹配 GT 311327，同时丢失 GT 189623。联合组平均比单帧低 0.52 个百分点，**预设晋级门槛未通过**，不自动扩场景或搜索阈值。

已有产物复核定位到 SceneNN GT 745473：单帧组将两组观测关联为同一对象，IoU 从基线/联合组的 0.538 提升到 0.835；这个差异在 history2 之前已存在，相关分支没有图合并提案或最终合并。不能据此断言原因是跨窗口特征漂移，但可以排除这个案例中“联合组已有改善被后处理抵消”的解释。

保留 VGGT 单帧为候选强基线，暂不替换已冻结主线。四帧联合特征直接替换分支到此封存；未训练对象记忆仍需另行设计训练与消融，不能用本轮分数替代其验证。

## 固定实验

| 项目 | 配置 |
|---|---|
| 数据 | Replica office_0、SceneNN 014，各 200 个既有采样帧 |
| A：原关联基线 | SigLIP + CG + history2 |
| B：控制组 | VGGT 单图最后层描述子 + 同一建图后端 |
| C：联合特征候选 | VGGT 四图联合最后层描述子 + 同一建图后端 |
| 保持一致 | 原 SAM 掩码、测量点、位姿、seed=0、关联阈值、history2、最终去噪与合并 |
| 语义读出 | 三组均使用原 SigLIP 特征，不将 VGGT 特征与 SigLIP 文本向量比较 |
| 预算 | 2 场景 × 3 组 = 6 张地图，不扫描阈值、不替换失败场景 |
| 指标 | 固定参考表面上的实例 PQ、TP/FP/FN、逐对象 IoU、混合对象与碎片化错误特征 |

四图窗口按时间顺序划分，不重叠，尾部不足四帧仍保留。单图和联合组使用同一权重、预处理、层数和掩码面积池化。联合组可访问窗口内未来图像，因此属于离线窗口方式。不同窗口的描述子是否一致，是待验证的限制。

6 张地图全部完成并封存后才读取参考标签评分，投影固定为 nearest_5cm。所有组使用同样的最终处理；本轮未叠加旧可见性清理模块，避免混淆关联特征的影响。保持阈值也意味着这是原配置下的迁移对照，不代表分别调优后的最佳结果。

这两个场景已参与开发。所谓完整序列是覆盖已有 200 帧采样轨迹，而非逐张处理所有原始 RGB 图像；结果不是独立测试或官方榜单成绩。

## 预设决策

联合组的两场景平均 PQ 必须同时超过单图组和原 SigLIP 组，且相较 SigLIP 的总 TP 不减少，才进入新的冻结独立评测协议。逐场景和逐对象损失必须同时公布。未通过时仅依据已保存结果复核一次机制，不自动追加参数搜索。

本轮通过也仅能支持联合视觉特征的作用，不能替代对象记忆、历史归属修订模块的训练与独立消融。
