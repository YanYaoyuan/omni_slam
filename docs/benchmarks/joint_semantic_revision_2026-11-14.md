# 对象类别验证与局部几何修订：固定对照已完成

**主线保持为 omni_slam 持续对象级语义建图。** LIVO 提供位姿和实测几何，研究目标是对象完整性、准确性、跨帧身份一致性及可追溯更新。当前候选只验证固定身份上的类别/几何修订，不代表对象发现、身份关联或整个 SLAM 的创新。

**本轮候选未通过，封存、不替换强基线。** 完成两个已暴露室外窗口和330帧车库的同模块对照，9份有效新地图、6次有效公共评分，无新训练或模型前向。平均AP只提高0.000735个百分点，且与仅改类别完全同分，没有新增AP50匹配对象；联合机制没有显示独立收益。有效机制及真正独立泛化尚未完成，不能把本轮链路跑通当作总目标完成。

## 方法与固定控制

使用已有19类SegFormer观测概率和已封存Utonia几何反证。按真实相机观测帧聚合，而不是按点的采集帧冒充重复观测：同帧去重 `(单元,对象,像素)`，先均衡对象的单元，再均衡观测帧。

复核一个20厘米单元时，从对象统计中剔除该单元的全部观测。若剩余证据存在，计算 `19 * dot(单元概率, 其余对象概率)`；低于 `1−1e−6` 才认为语义不兼容。该均匀参照分数是建模假设，不是概率校准或观测独立性保证。只有语义不兼容同时支持原几何撤回提议，才撤回该来源锚点。所有采集帧锚点都撤回后才撤回整个单元/对象归属，随后沿原图重算传播。

对象类别根据帧均衡概率更新一次；联合方法在完全撤回单元后重估类别。保留全部原坐标、对象ID及排序分数，只有类别和部分点的未分配状态可以变更。缺观测保持原类别/归属。没有新增对象、补点、训练或阈值搜索。

五组控制：

- **Baseline**：冻结原地图。
- **Geometry only**：复用上一轮完整几何撤回结果。
- **Class only**：只改类别。
- **Simple fusion**：独立组合上两项。
- **Ours（候选）**：语义条件化几何撤回，然后重估类别。

前两组地图和分数复用旧产物，其余三组每场景各导出一次有效地图。类别适配本身是控制，不作创新主张。所有预测在读取参考标签前封存；这些窗口已有历史开发使用，不属于独立测试。

## 正确导出后的完整地图结果

KITTI-360本地适配building/car **AP50:90（%）**，不是官方榜单。

| 方法 | 0000 | 0002 | 两窗口平均 |
|---|---:|---:|---:|
| Baseline | 23.674470 | 32.349298 | 28.011884 |
| Geometry only | 26.140355 | 30.977252 | 28.558804 |
| Class only | 23.675939 | 32.349298 | 28.012619 |
| Simple fusion | 26.141825 | 30.977252 | 28.559538 |
| **Ours（候选）** | **23.675939** | **32.349298** | **28.012619** |

Ours的AP50为38.674358/41.922357，相对基线无新增、无丢失匹配。全部目标GT最佳同类IoU相对基线：0000改善1、退步2、不变46；0002改善1、退步2、不变42。该最佳IoU读出与AP匹配分开报告。

原协议要求两窗口AP/AP50均不退步、无丢失匹配、平均至少增加0.1个百分点且严格超过三个控制。Ours不满足增幅和控制优势，`development_gate=false`。Simple fusion虽然均值更高，但0002退步，也不能升级成稳定有效方法。

## “为什么同分”的实际证据

Ours与Class only在0000/0002分别有**55/100个地图点**归属不同，投影至参考域后分别改变**243/501个查询**的身份，2/3个目标GT的最佳同类IoU改变。但两组AP完全相同，属于真实几何变化未形成AP改善，不是复用同一预测文件。

联合条件只接纳28/28个原几何撤回提议（原提议4,848/4,347个），最终类标签与Class only相同。0000一个对象由building变为vegetation；0002对象1和34由car变成building。上轮参考诊断显示后二者主要是truck/motorcycle，因此本轮没有正确完成这两个细分类别修订。没有按GT将它们手工改为车辆子类。

本轮不能证明仅靠这组概率均值及兼容条件能可靠修正对象类别，更不能把几何改动极少、保留原正确点当作完整对象恢复。

## 同版本机器人结果

读取rosbag2245全部330帧已有语义缓存，其中263帧包含旧前景来源的有效观测；其余帧不冒充前景证据。61个对象使用同一规则。Ours接纳6个锚点撤回提议，将19个地图点设为未分配，4个对象类别由car变为building。Simple fusion撤回8,342点。

机器人无独立GT，这些数字只证明同版本链路与真实地图变化，不能声明精度提高或对象类别改对。没有S100实机、实时性能或在线因果性结论。

## 导出问题、修复与核验

本轮新增导出的首次实现存在类别映射问题：KITTI-360中building原始ID11与garage原始ID34共用train ID2；反向字典取最后一个条目，把保持building的对象也导出成garage34，随后被当前评测器忽略。问题在本轮新增导出器，不是已确认的旧基线错误。

首次9份导出、6次分数及报告已完整存档并标为无效。修复采用与冻结模型配置一致的首个规范标签，并严格保持未变类别的原字段。原协议未重写；修复和代码哈希以单独修订记录关联。相同9份地图重导出、6次评分重算。**这额外计算属于实现修正，不是增加候选、阈值、窗口或模型调用。**

修复前后9份地图的所有几何数组、所选train类别、语义概率、排序分数逐项完全一致；只纠正类别名称/原始ID。以本报告修正后数字为准。

核验完成：

- 7项针对性测试通过，含40组随机显式留单元重算、同train ID不同原始ID回归测试。
- 72个真实单元另作显式观测帧重算；联合撤回集合和全部单元撤回条件精确核验。
- 三场景所有坐标、身份、类别字段与固定分数核验。
- 两公共窗口共10份参考投影重放，逐方法/逐对象差异保留。
- 原输入和父实验失败门槛保持不变；图片已人工查看。

协议首次写入前还修复了路径字典JSON键类型错误；当时未产生协议、预测或评分。

## 主线去留决定

关闭这个固定身份的兼容门控版本，不追加阈值/均衡权重/概率融合试验。它不能作为论文核心，也不据此否定对象级建图方向。

后续工作仍须围绕**完整对象恢复与可靠更新**：用完整地图证明多恢复了哪些正确对象、修正了哪些错误归属，同时报告损失；通过强基线和同输入简单控制后，再进行真正未参与开发的公开评测及同版本机器人验证。不能再把局部分类AUROC、稀少删点或模型接入作为下一轮质量改善的充分依据。此次没有自动启动另一条分支。
