# 地图级归属训练：完整对照与候选空间上限

主线是 **omni_slam 持续对象级语义建图**：对象形成、跨帧身份、三维几何和历史修订，LIVO 提供定位及实测几何。本轮实际实现并训练地图级接纳机制，完成完整地图比较；不是继续运行外部模型能力探针。

**候选没有涨点，不替换强基线。更重要的新结论是：在本轮固定候选空间内，即使理想地选择点，也不可能新增 AP50 正确匹配。** 因而“至少新增一个匹配”的开发门槛在训练前就不可达。这是实验设计缺口，应先做容量预检，不能归因于模型还没训练够。后续不再围绕这一固定旧ID、仅追加的候选池换损失、阈值或训练轮数。

## 本轮实现的机制

一个候选测量被接纳后，可能在空间读出中替代另一个点。逐点分类正确，不保证完整对象的交集增加或污染减少。本轮把这项空间竞争纳入训练。

在训练参考位置上，按距离检查所有比旧地图点更近的候选测量。第一个被接纳的候选决定标签，全部拒绝则回退到原地图。若候选点的对象选择概率为 `p(s,o)`，其贡献乘以所有更近候选的拒绝概率。由此计算各对象的预测面积质量 `M` 和与固定训练目标的交集质量 `I`。

对有训练目标的对象优化 `1 − I / (G + M − I)`；未匹配预测也保留，以 `M / (M + s)` 处罚其面积，`s` 为同类别训练GT的平均质量。目标匹配在训练前按类别约束的最大总IoU一对一分配固定，只保留正IoU配对；未匹配对象不偷偷删除。未知标注权重为零，已知道路等背景仍提供负证据。

这是**期望统计量的比值代理损失**，不是IoU或AP的精确期望。空间排序是欧氏最近点次序，不是相机射线遮挡推理；普通可微读出和IoU损失本身不作新颖性主张。

## 四组公平控制

| 条件 | 训练监督 |
|---|---|
| Point | 候选来源点的类别/归属交叉熵 |
| Object balanced | 相同点标签，按目标对象及null均衡 |
| Mean neighbor | 地图级监督，均匀混合邻近候选及其回退概率，去掉最近点竞争 |
| **Ours candidate / Ordered map credit** | 相同地图级监督，使用精确的有序竞争边缘概率 |

四组共用候选池、50维几何/语义/对象残差特征、50→32→32→1网络、null分支、训练窗口、初始化与优化步数。地图级两组还共用全部训练参考位置与标签，区分“用了更多空间监督”和“建模了近邻竞争”。

所有模型使用seed0、Adam学习率0.001、120次全批次更新，取最后一步，无验证集选轮次或阈值搜索。两块5090分别运行一个训练方向，共八次拟合；网络FP32，分类概率和地图统计FP64。随机种子不等于CUDA散射求和的逐位复现保证。没有基础模型新推理。

当前基线为冻结 `batch_stable_transport/ours_frame`，均值AP28.012，未退回较弱的历史23.134版本。候选从旧共享提议中去掉距离**当前基线**5厘米以内的来源，剩25,300 / 29,306个实测点；输出保留旧坐标、ID、类别和排序，只能追加真实测量。

训练为0000→0002、0002→0000两方向。两个窗口都已反复开发，上游还有交叉监督继承，**不能称为独立测试或无泄漏嵌套交叉验证**。新拟合只解码其指定训练窗口的参考标签；推理不输入参考坐标或标签。

## 完整地图结果

KITTI-360本地适配building/car AP50:90，单位为百分点；不是官方榜单。八份预测全部封存后统一评分。

| 方法 | 0000 | 0002 | 均值 |
|---|---:|---:|---:|
| 冻结强基线 | 23.674470 | 32.349298 | **28.011884** |
| Point | 23.674470 | 31.517274 | 27.595872 |
| Object balanced | 4.043763 | 5.780739 | 4.912251 |
| Mean neighbor | 23.674470 | 32.349298 | **28.011884** |
| **Ours candidate** | **23.674470** | **32.349298** | **28.011884** |

候选新增/丢失AP50匹配均为0，未超过控制，开发门槛false。不能将不退步写成有效改善。

| 条件 | 0000追加来源数 | 0002追加来源数 |
|---|---:|---:|
| Point | 0 | 5,555 |
| Object balanced | 18,312 | 28,574 |
| Mean neighbor | 0 | 207 |
| Ours candidate | 0 | 2,063 |

**本次同分原因已核实：** 0000的Point及两种地图监督均拒绝全部新候选，实际地图与基线相同。0002的Ours与Mean neighbor有1,856个来源决策不同；Ours使5个GT的最佳同类IoU改善、5个退步，其余不变，但没有形成AP变化。不是重复预测文件。全部94个对象均在报告中列出，最佳IoU诊断与AP匹配分开。

## 新发现：候选空间不能新增匹配

在已经封存的预测之外，只作GT辅助上限诊断，不生成新方法地图：放松每个参考位置的选择，让它独立选择旧图回退标签或任何更近候选点允许的对象ID。

对某对象 `o` 和GT `g`，这个放松问题的最优IoU是：

`最大可能交集 / (GT质量 + 不可避免的GT外预测质量)`。

只有当某位置的所有可实现标签都为 `o` 时，其GT外污染才不可避免。真实源点选择会同时影响多个位置，而这个放松允许它们独立选择，因此得到的是乐观上界。每个GT还可独立选择最有利的预测ID，选择之间可能冲突；这些值不能当作可实现地图或AP。

| 当前候选空间 | 乐观上界仍≤0.5的漏检建筑 | 任何漏检GT有机会新增越过0.5？ |
|---|---:|---|
| 0000 | 17 | **没有** |
| 0002 | 18 | **没有** |

30个随机小问题与逐参考位置穷举最优值一致；全部已评分地图的逐对象IoU均不超过这个上界。该结论仅约束**这批候选、允许ID及不可变旧地图**，不约束新的对象提议、历史修订或新ID形成。它也不证明所有更高IoU阈值处的AP都不可能改善。

这比“再多训练几轮”更明确：本轮候选空间可以修补某些已有对象边界，却不能完成新增正确对象的验收项。此前[完整对象形成诊断](object_formation_limits_2026-11-14.md)显示有12个漏检建筑具备足够原始测量覆盖；问题不能等同为所有表面都没采到。下一机制必须改变可分配的对象/表面空间，不能继续固定当前提议池。

## 训练与实现核查

- 四项针对性测试通过：联合选择穷举、确定性端点、未知标注弃权、控制差异、自动微分和未匹配惩罚。
- 两窗口共2,304个真实参考位置与另一套已验证的稠密概率读出一致，面积最大差1.71×10⁻¹³、交集差0；全部5,983,698个参考位置的拒绝回退标签一致。
- 八份新地图的旧前缀、实测新增坐标、唯一来源归属、类别和排序逐项核验，八份完整参考投影精确重放。
- 两个训练方向的目标匹配分别36/31个，未匹配11/5个；未匹配代价明确纳入地图监督。点监督正例为3,572/20,815及570/24,131，均衡后大量接纳并没有改善地图。
- 标准化没有触发零方差下限；存在明显目标特征分布变化，但这不能单独解释拒绝，也不据此追加归一化变体。
- 首次报告审计对跨NumPy运行时的浮点概率要求逐位相同，因约1.11×10⁻¹⁶舍入差停止。原脚本/失败记录已存档；离散决策始终精确一致，概率改用4 ULP核验。没有重训、改预测或重算评分来修饰结果。
- 五张实际地图/RGB/训练图均已查看。GPU训练峰值分别约1.08/0.80 GiB；这不是完整建图运行显存或S100实时性能。

## 主线决定

封存本轮，保留强基线。地图级损失已被实际训练和完整评测，不再列为“尚未试过”的候选；不继续围绕当前固定ID、仅追加的池做损失/阈值变体。

下一轮在训练或建图之前，必须同时通过两项预检：验收观测域非空；候选空间有能力改变目标对象形成结果。随后需要实际实现包含新对象形成或历史归属修改的机制，并完成强对照、同版本机器人及未参与开发的评测。此次只是主线中的训练机制验证，**有效新机制、完整机器人对照、独立新增评测三项目标均不能据此标完成。**
