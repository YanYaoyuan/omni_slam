# 主线机制复核：区分身份辨识与目标外污染

本轮完成真实108帧的掩码模式辨识检查，以及旧失败地图的语义错误分解。
没有生成新地图、训练新的神经网络、调整阈值或扩展独立测试；旧强基线保持冻结。
[图文报告](../../output/mask_observation_code_probe_v1/index.html)包含真实RGB、验证源点与完整数字。

## 对下一步的实际影响

**当前优先问题是未归属测量的目标/环境判别，不是继续复杂化已有对象身份解码。**
这是对本轮检查范围的结论，不代表所有地图错误都已归因，也不证明身份关联问题普遍解决。

对上一版 `surface_evidence_field_v1` 的冻结输出，沿用原始AP50正确对象的诊断范围，
进一步恢复原始语义标签，避免把 trainId=0 的道路与 trainId=255 的忽略区域混在一起。
新增地图点所负责的**错误参考置信度面积**分解如下：

| 类型（错误面积内部占比） | 0000 | 0002 |
|---|---:|---:|
| 其他已知语义类别 | **90.58%** | **89.14%** |
| 同类其他或未细分实例 | 4.06% | 2.44% |
| 忽略标签区域 | 5.36% | 8.42% |

其他已知类别中植被占比最高，还包括墙、路面、人行道、围栏等。
这不是源点分类准确率；也不是干预某一模块后的AP因果归因。
同目标正确面积及目标外面积与上一轮错误来源审计逐项核对一致。

## 为什么不继续本次复杂解码

将原强基线对象的实测源点，按固定2米空间块分为建模与验证两部分。
每帧使用精确实测可见像素，不把20厘米邻点可见当成该源点可见；同帧重复掩码去重。
每个候选需至少16个建模单元，至少两个对象共同参与辨识。多个原始测量落入同一物理单元时等权。

完整模式使用对象核心上的Beta平滑成员频率，同时读取掩码包含与排斥信息。
它只是相关观测的平均Bernoulli分数，不能解释为校准后验。相同分数弃权。
单掩码控制仅给所覆盖验证点赋一个核心覆盖率；另设余弦掩码亲和度、随机打乱模式和几何最近邻控制。

以下是**与预测核心ID的一致率**，按对象宏平均；不是语义真值准确率或完整地图AP。

| 控制 | 0000 | 0002 |
|---|---:|---:|
| 单掩码覆盖率 | 81.000% | 83.943% |
| 简单掩码亲和度 | **99.585%** | 99.825% |
| 完整掩码模式 | 99.232% | 99.746% |
| 打乱掩码模式 | 21.647% | 25.258% |
| 几何最近邻 | 99.584% | **99.986%** |

0000覆盖41/47个预测对象、62950个留出源点；0002覆盖35/36个预测对象、51277点。
缺少建模支持的对象没有纳入上述一致率，覆盖数量已显式报告。
上游对象地图和掩码仍用过这些观测，本轮空间留出仅隔离解码器拟合；不是独立测试。
核心伪标签也可能错误。继承的几何强基线包含跨窗口监督模型，完整管线不能称为免训练。

完整模式没有达到冻结筛选条件——两个窗口均不得落后简单亲和度。因此关闭本次解码候选，
不尝试重新加权、训练该模式或扩展完整地图来挽救结果。5项针对性测试通过。
这避免了把更复杂的读取方式直接投入又一批地图实验。

## 与已有工作的界限

[SAI3D](https://arxiv.org/abs/2312.11557)已通过多视角SAM掩码关联几何基元；
[MV3DIS](https://arxiv.org/abs/2604.08916)进一步用粗3D分割指导掩码匹配，并建模深度一致性。
因此多视角亲和度、图合并或Bernoulli解码本身不能作为原创贡献。
本轮亲和度仅为共享输入的简化控制，不是上述原版算法的完整复现或官方成绩。

## 下一机制的约束

主线仍是 omni_slam 对象级语义建图，LIVO提供定位和实测几何。
下一项应检验对象本体、环境解释与未知之间的竞争能否改善**未归属点的接纳**，
而不是把已有对象的身份一致率作为最终目标。对象查询低分、缺测和明确环境反证必须区分。
新机制需要与原几何强基线、简单语义背景排除以及相同输入的独立接纳器比较，
防止把常规背景去除包装成创新；具体生产算法尚未冻结，不能按本次诊断直接宣称成立。

完整地图开发验收通过后，才固定配置执行真正未使用的室外场景和同版本机器人对照。
0000/0002/0004/0005均已暴露；现有机器人参考链路不能替代有效新机制的机器人验证。
**新机制、对应机器人对照和新增独立评测的完整目标仍未完成。**
