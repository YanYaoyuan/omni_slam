# 对象划分目标与观测信息：机制决定

日期：2026-11-14。主线：omni_slam 持续对象级语义建图。

**结论：关闭当前类别计数兼容性目标；保留强基线。** 已发现它与真实对象划分的明确错位，继续优化该目标不等于改善对象地图。原始多掩码候选有额外信息，但单纯软加权没有超过几何控制，不能直接作为新方法贡献。

## 1. 什么是本次新证据

使用上一轮冻结的两个 KITTI360 开发窗口，不重新建图。将全部实测来源点以固定 20cm 最近邻规则投到原始 building/car 参考身份，保留一个单元内全部来源标签一致、且与预测类别相符的单元。其余单元在所有目标比较中共同排除。

| 检查 | 0000 | 0002 |
|---|---:|---:|
| 纳入单元 / 全部候选单元 | 25,032 / 47,761 | 18,642 / 54,683 |
| 纳入来源点 | 339,257 | 230,240 |
| 有诊断支持的原始对象 | 45 | 36 |
| 多碎片对象合回整体后目标变差 | 40 / 45 | 30 / 33 |
| 仅同一对象、图内连通部分：合回后变差 | 43 / 51 | 34 / 36 |
| 混合预测区域按真实身份拆开后目标变差 | 43 / 48 | 23 / 27 |

比较的观测完全相同，只改变聚合分组。目标越高越好，因此这些负变化表明目标可能偏好错误拆分和错误合并。图内连通检查排除了“根本不存在合并路径”这一种解释。但这是移除未知/混合单元后的反事实诊断，不能精确归因全部完整地图 AP 的下降。

数学上的具体问题是：同一帧两个单位质量观测若使用不同类别 token，合并增益恒为 `-log(2)`，与词表大小无关；不同掩码可能只是同一物体的两个部分。两个窗口 45/45、34/36 个有支持的对象至少在一个视图中包含多个 token。相反，多个真实对象共享相同掩码，也可能被该目标奖励合并。这说明“掩码身份”不能直接充当“物理对象身份”。

## 2. 原始候选是否保留了额外信息

另行预先固定协议，在全部跨预测区域候选边中，用相同的共同可见帧比较四种配对分数。最高分掩码版按原始像素赢家构成直方图；全候选版累加每个正分原生掩码的覆盖点数乘原生分数，归一化后取两个端点直方图的交集。无新阈值、参数拟合或模型前向。

| 同对象配对 ROC AUC | 0000 | 0002 |
|---|---:|---:|
| 最高分掩码 | 0.545720 | 0.451386 |
| 全部原生候选 | 0.646934 | 0.626985 |
| 几何距离控制 | **0.987064** | **0.988531** |
| 原类别目标的初始合并分数 | 0.512606 | 0.427934 |

全候选在两个窗口及建筑/车辆分层均超过最高分选择，通过预定的“信息保留”门槛。这个门槛只允许认为原始候选有额外区分信息，**不代表算法验收通过**；同域几何距离仍明显更强。

限制必须同时保留：

- 共同域仅包含 9,547/9,182 条边，同对象边为 9,392/9,020 条；正类极不均衡，配对 AP 接近 99% 不是高建图精度。
- 几何控制所用域排除了混合/非目标单元，不能据此推断它能处理完整地图中的背景污染。
- 事后局部/非局部分层显示，局部边仅有 2/4 条跨真实对象负例；这些边并非独立样本，不能作强泛化或显著性主张。
- 查询链独有边上，全部候选 AUC 为 0.700883/0.718496，几何距离为 0.926498/0.970014。全候选改善不是仅由局部边比例造成，但仍没有超过几何控制。
- 本诊断使用所有有支持的原始对象，不限定为完整地图 AP 的合格 GT 清单；其对象数不能与之前 94 个主评测对象直接相加或对比。

## 3. 机制去留与下一步

不再改变当前类别目标的先验、权重或合并门槛，不把全候选加权包装为创新。新机制的设计约束收敛到：**以实测几何连续性形成对象候选，用多视图证据检验对象整体及其边界；不同掩码本身不作为异物判据。** 需要保留候选不确定性，但是否保留必须服从整体对象判别，不能再次变成独立的配对分数优化。

下一项完整建图实验必须纳入几何控制，同时核对新增正确对象、错误实例与历史对象损伤。不得仅通过当前这批已筛选配对证明有效，也不得回到固定旧 ID、仅允许追加点而无法恢复漏检对象的候选空间。实现和预算须在新地图评分前固定，旧失败分支保持冻结。

本轮尚未实现并验证符合上述约束的新方法。当前强基线两窗口均值 AP50:90 仍为 28.011884%；失败的整体区域候选仍为 13.031126%，未重评分。有效机制通过完整地图开发验收后，才能扩展同版本机器人及真正未使用的室外数据。目标保持未完成。

## 4. 核验与产物

全部 5,441 个聚合目标检查与独立 `scipy.gammaln` 实现一致，最大绝对差约 `5.7e-12`；432 次原始掩码标量读出通过；48 个配对 AP/AUC 指标用独立排序实现复现。两张新科学图已查看，报告同时引用此前真实 RGB/地图叠加图，未生成新的地图展示结果。

初次启动的坐标一致性检查误将原始全局坐标与局部评测坐标直接比较，立即报错停止。改为减去原 job 的 `origin_world` 后，坐标、顺序、参考权重精确核对通过。该初始化失败单独保留，未产生诊断分数或地图；未改预测和原评测数据。
