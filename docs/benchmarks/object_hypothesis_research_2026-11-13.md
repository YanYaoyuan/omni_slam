# 对象归属冲突驱动的取证与修订：源码调研和研究决定

2026-11-13。响应用户要求：研发以新机制为中心，不安排独立的工程补齐任务。本轮读代码、复核旧实验、定义研究假设；没有启动训练、SAM 推理或新建图。本文是设计，非已实现方法或新结果。

## 2. 必须避开的重复路线

- [MaskClustering](https://arxiv.org/abs/2401.07745) 已经使用其他视角的掩码共识构建并聚类全局掩码图。仅加跨帧投票、图优化或合并不能建立新颖性。
- [B³-Seg](https://arxiv.org/abs/2602.17134) 已经提出 Beta–Bernoulli 分割更新和基于解析信息增益的视角选择。不能把“主动选视角 + SAM + 概率更新”作为首次提出。
- [IJCAI 2026 系统演示](https://ijcai.org/proceedings/2026/967) 已展示以增量场景图作为建图后端的开放词汇系统。因此系统集成和持久图也不足以单独支撑新算法主张。

上述只是当前检索到的直接近邻，尚非穷尽式新颖性核查；不宣称首次。

我们自己也已有失败证据：[重分割复核](../reports/memory_mechanism_audit_2026-11-12/report.md) 发现候选既有收益也有损伤，并且有局部分离未保留到对象地图；[拆分复核](../reports/reversible_revision_2026-11-13.md) 中 v1/v2 验收均无接受。新方法不能复用同一失败逻辑后改名。

## 3. 选定的研究假设

**在固定额外感知预算下，由竞争的对象归属解释共同决定取证视角及提示，再用未参与提示的真实视角验证，可以比通用重分割更有效地恢复完整地图中的实例。**

目标是优化对象划分及其证据获取，不是提高前端分辨率、只重排置信度或继续删点。第一版不要求训练，也不指定 Transformer。

例子：相邻两辆车因斜视掩码连在一起。保存“同一对象”和“两个对象”两种解释，寻找两种解释在实测可见区域最容易区分的历史图像，分别用两种解释导出对称提示。新分割可以提出修订，但不能自己为自己验收；另一视角的测量决定是否改写历史点归属。相反，两段互补车身可能支持合并，不能预设拆分总是正确。

### 可实现的核心定义

1. **局部竞争解释。** 在有来源的观测片段上建立保持、合并或重新分配的有限候选集合；允许“尚未成为对象的观测”参与。候选来自当时可用的观测冲突，不读取 GT 或未来最终成员关系。首版先处理片段与待确认观测的归属，避免重新开展无约束 DINO 二分。
2. **选择能区分解释的取证动作。** 一个动作是“真实历史视角 + 局部区域 + 对称提示集合”。候选之间比较的是源点对是否同属一个对象，不直接比较任意编号的 ID。仅统计双方都有有效深度支持的可见点对；遮挡和 LiDAR 无返回保持未知。用归一化的划分分歧、可见支持及视角冗余惩罚构造效用，按实际感知开销分配预算。它是分歧效用，不冒称严格的期望信息增益或具有近似最优保证。
3. **公平地产生新证据。** 同一局部区域对竞争解释分配相同提示/解码预算，保存提示、原图与源点关系。否则地图中原占优势的解释可能因更强提示而被反复确认。模型产生的 mask 是带偏差的候选证据，不是真值。
4. **分离取证与验收。** 预留未参与候选生成、动作选择和提示的视角组；对候选统一计算其对实测掩码及深度的解释损失，加入固定复杂度惩罚。验收视角不接受候选专属提示。只有证据区分明确才提交。候选数量和验收规则须先固定，不能循环搜索验收帧。
5. **提交对象归属。** 更新历史观测和源点的对象分配，而非仅把新 mask 重新送进旧 CG 整块融合。保留保持原状的候选、唯一源点归属和可追溯操作；仅使用测到的几何，不补造未观测表面。首版按离线重放评价，不宣称机器人主动移动或实时在线能力。

这一方向的潜在贡献是：**围绕地图归属错误，联合设计“要验证什么、用什么观测验证、证据如何改变历史对象”**。这些单项都有先例；论文需要证明联合机制有区别、有独立增益，不能靠命名确认创新。

### 与旧注意力重提示的区别

旧版：对当前掩码读取记忆、生成一个划分、按旧 CG 融合；既不选择最有区分力的历史视角，也不显式比较对象解释并修订历史归属。

新假设：竞争解释驱动选择和对称取证，由分离视角裁决并改写历史归属。若实际实现退化为“更多裁剪 + 原 CG”，则没有实现本假设。

## 4. 一次有限验证怎样支撑论点

先复用已暴露的 KITTI-360 开发窗口和一个已暴露室内开发场景。保留的 KITTI-360 两窗口不在开发中评分。独立测试在机制验收和参数冻结之后进行；不同数据集指标不能混成一个均值。

候选实现前先固定动作数、局部图像尺寸、SAM 编码/解码总预算、重复视角分组、候选上限和验收损失。以下为设计预算，尚非参数已冻结的执行协议：最多两场景 × 六个条件 = 十二个新地图，不安排阈值扫描。

| 条件 | 支撑的比较 |
| --- | --- |
| 均匀分配普通局部重分割预算 | 额外感知本身能带来多少收益 |
| 相同修订器 + 随机选视角 | 选择策略是否有增益 |
| 相同修订器 + 最大可见面积选视角 | 是否只是选更清楚的图 |
| 相同修订器 + 单点不确定性选视角 | 对象划分分歧是否优于普通不确定性 |
| 完整选择和取证 + 只更新当前观测 | 历史归属修订是否有必要 |
| 完整候选方法 | 联合机制的最终效果 |

已有冻结强基线、SOR、simple ratio、MaskClustering 共享核心保留在结果表。除专门消融项外，共享候选空间、分割器、类别读出、几何源、最终处理和评测协议。计入全部额外编码、解码、选择及验收成本；不能只对齐调用次数却让像素预算不同。

主指标是完整地图 AP/PQ、实例召回及新增/丢失正确匹配；辅以归属修改正确性、未触发率、成本和逐对象可视化。必须区分新几何收益、身份收益与置信度排序收益。

继续条件：两个开发场景均优于本轮最强等预算控制，均有净新增正确实例；完整策略较当前观测更新消融有可归因的收益。若所有版本同分、无有效提交，或收益完全来自普通重分割，停止该机制版本，不将其包装为成功创新。开发通过也不等于独立泛化或论文录用。
